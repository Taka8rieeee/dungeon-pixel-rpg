# 地牢像素 RPG

零依赖、离线、随机地牢的像素 Roguelike。
用 Node.js 写服务端与引擎，浏览器 Canvas 呈现画面，不安装任何 npm 包。

```
node server.js
```

然后打开 <http://localhost:4321>（启动时会自动打开浏览器；设置 `NO_OPEN=1` 可关闭）。
端口被占用时会自动顺延（4322、4323…）。

---

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 移动（一步 = 一回合） |
| `↑` `←` `↓` `→` | 朝该方向攻击 / 射击 |
| `Q` | 喝药水（回复 40% 生命） |
| `空格` | 原地等待一回合 |
| `1` `2` `3` | 升级时选择强化 |
| `Enter` | 标题 / 结算界面开始新一局 |

移动与攻击是分离的（类似以撒的结合）：一边用 WASD 走位，一边用方向键朝四个方向出手。
武器决定攻击形态：铁剑 1 格、长矛 2 格、短弓 6 格弹道。

---

## 已实现（v0.1 骨架）

- **随机地图**：48×32，房间+走廊为主，第 2/4 层为洞穴；每层 1 个隐藏房（攻击裂墙进入）。
- **视野**：递归阴影投射，当前视野 + 已探索灰影。
- **回合制行动值**：每个单位有速度，行动条攒满出手一次 —— 攻速 build 因此成立。
- **战斗**：暴击、暴击伤害、吸血、防御减伤、击退型走位（速度差可以风筝）。
- **敌人**：史莱姆 / 地鼠 / 邪术师（远程）/ 暴徒 / 层主 / 地牢之主（会召唤援军）。
- **局内成长**：经验升级 → 三选一（10 种强化池），三条流派（攻速 / 暴击 / 吸血）都能走通。
- **层主**：每层楼梯由层主把守，击败后解锁楼梯并回复 25% 生命；第 5 层是最终 Boss。
- **局外成长**：晶石（只由 Boss 掉落）→ 生命上限、攻击力各 5 级（+30% 上限）。
- **道具**：金币、药水、宝箱（换武器）、生命护符（死亡自动复活一次）。
- **存档**：`data/meta.json`，写盘前自动备份为 `meta.bak.json`。
- **调试**：`/api/debug/goto`（跳层）、`/api/debug/shot`（把画面存成 `data/shot.png`）。

## 目录结构

```
server.js              零依赖 HTTP 服务：静态文件 + JSON 接口
src/
  game.js              游戏状态机：回合、战斗、掉落、升级、胜负
  mapgen.js            房间/洞穴/隐藏房生成
  fov.js               视野（递归阴影投射）
  rng.js               可复现随机数
  save.js              局外存档读写
tools/
  gen-assets.js        用 zlib 手写 PNG，生成 16×16 像素图集
  logic-test.js        逻辑单元测试（不启动服务器）
  gen-test.js          地图生成压力测试
  smoke-test.js        让简易 AI 对着运行中的服务器自动试玩
public/
  index.html
  style.css
  client.js            渲染、输入、界面
  assets/atlas.png     生成的图集
  assets/atlas.json    帧索引
data/
  meta.json            局外存档（首次运行自动生成）
```

## 开发

```bash
node tools/gen-assets.js      # 重新生成像素图集（改完美术后跑）
node tools/logic-test.js      # 逻辑测试
node tools/gen-test.js 200    # 每层生成 200 次，检查连通性
node tools/smoke-test.js      # 需要服务器在跑：AI 自动试玩一局
```

### 接口

所有接口都在本机，返回完整状态：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 当前状态 |
| POST | `/api/start` | 开始新一局 |
| POST | `/api/action` | `{action:{type:"move"\|"attack"\|"wait"\|"potion",dx,dy}}` |
| POST | `/api/choose` | `{index:0..2}` 升级三选一 |
| POST | `/api/upgrade` | `{stat:"hp"\|"atk"}` 局外升级 |
| POST | `/api/reset` | 清空局外存档 |
| POST | `/api/debug/goto` | `{depth:1..5}` 跳层（调试） |
| POST | `/api/debug/shot` | `{data:"data:image/png;base64,..."}` 存画面（调试） |

游戏逻辑全部在服务端：浏览器只负责发指令和画状态，改数值不需要动前端。

## 已知限制

- **局内进度不落盘**：关闭服务端会丢失当前这一局（局外晶石和升级会保留）。
- 数值（敌人强度、掉落、升级价格）是第一版拍脑袋定的，需要试玩调。
- 没有音效、没有存档槽、没有成就系统、没有移动端适配。
- 中文使用系统字体（像素中文字体体积大且有版权问题）。
