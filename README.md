# 地牢像素 RPG

零依赖、随机地牢的**实时动作**像素 Roguelike，**无尽向下**：没有终点层，死亡才结束。
支持**多人同屏联机**：最多 4 人进同一座地牢，服务器权威模拟，共享地图与掉落。
游戏逻辑全部跑在浏览器里（`public/engine.js`），Node 只负责发静态文件和读写局外存档，不安装任何 npm 包。

在线试玩（公网联机）：<https://dungeon-pixel-mp.app.workbuddy.host/?sharecode=YYCNLIYBQ4>

```
node server.js
```

然后打开 <http://localhost:4321>（启动时会自动打开浏览器；设置 `NO_OPEN=1` 可关闭）。
端口被占用时会自动顺延（4322、4323…）。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 移动（实时，可斜向） |
| 鼠标移动 | 瞄准 |
| 鼠标左键 | 攻击（按住连发，受武器冷却限制） |
| `Q` | 喝药水（回复 40% 生命） |
| `E` | 捡起脚边掉落的武器 |
| `1` `2` | 切换两把武器（商店里用来购买，弹出选择框时用来选项） |
| `Esc` | 关掉商店 / 放弃全是武器的宝箱 |
| 鼠标滚轮 | 循环切换武器 |
| `M` | 音效开 / 关 |
| `Enter` | 标题 / 结算界面开始新一局 |

开局只有一根**旧木棒**——伤害低、范围小，好武器得往里走才能抢到。

武器栏只有 **2 格**：

- 拿到第一把武器会直接换掉旧木棒
- 栏位没满时，新武器进空格
- 栏位满了再拿新武器，会顶掉**当前手持**那把，旧武器掉在地上
- 走到掉落的武器旁按 `E` 捡起，会把你手上的那把留在原地，方便来回换

| 武器 | 机制 |
| --- | --- |
| 旧木棒 | 开局凑合用，没有特性 |
| 铁剑 | 均衡挥砍，连中三次后下一击爆发 |
| 长矛 | 突刺时向前冲一段，够得着远处 |
| 短弓 | 远程箭矢，能穿过一个敌人 |
| 战锤 | 慢速重击，击退并减速命中的敌人 |
| 匕首 | 极快，连续命中会越打越快 |

宝箱打开时会暂停，从**武器池与增益池随机刷出 3 个选项**（可能是纯增益、也可能是纯武器），只能带走一样。增益有六种：攻击 / 生命 / 暴击 / 移速 / 吸血 / **攻速（疾风之石，+7%）**，打乱后不重复，旧木棒不会出现。

选项**全是武器**时会多出一个 `都不想要（Esc）` —— 点了关掉界面，箱子留在原地，走开再回来可以重新开（内容会重刷）。只有选了东西箱子才会消失。

## 商店

每层都有一间**商店**，正常门口、走进去就开门（地面上带金色标记和「商」字）。买东西花的是**局内金币**，不是晶石。

价格**按层数小幅上浮**，每件商品再各自浮动 ±10%（取整到 5 的倍数），所以同一层两次进店看到的价格也不一样：

| 层 | 生命护符 | 武器 / 增益（护符的 75%，便宜 25%） |
| --- | --- | --- |
| 1 | 80 ~ 100 | 60 ~ 75 |
| 2 | 90 ~ 110 | 65 ~ 80 |
| 3 | 95 ~ 115 | 70 ~ 90 |
| 4 | 105 ~ 125 | 75 ~ 95 |
| 5 | 110 ~ 135 | 85 ~ 100 |

浮动后最贵的武器也始终比最便宜的护符便宜，不会倒挂。

货架每次进层重刷：2 把没拥有的武器 + 2 个增益，另有 **50%** 概率上架生命护符（已经有一个就不会再卖）。买完可以接着挑，`Esc` 关门。

价格是按金币产出定的：第 1 层能攒 ~80，第 2 层累计 ~170。护符通常要攒到第 2 层才勉强买得起，**买完基本就买不动别的了**——是「先买一张保命符」还是「先换武器」的取舍。层数越深东西越贵，但金币也涨得更快。

## 联机（同屏合作）

标题页点「联机同屏」→ 输入名字 → 和最多 3 个朋友进同一座地牢。

- **服务器权威**：`net/room.js` 里跑唯一一份世界模拟（60Hz），客户端只上报输入、接收 20Hz 快照，
  所以两端不会状态分叉，也不怕改客户端作弊。
- **零依赖 WebSocket**：`net/ws.js` 手写了 RFC6455 握手与帧解析，没有引入 `ws` 库。
- **共享与私有**：经验每人一份，升级三选一全队共享一次选择（效果加给所有人）；
  血量、金币、背包、武器各人各的。
- **倒下**：一名玩家倒下不结束游戏，全灭才结算；下一层开局全员复活。
- **掉线自动清理**：服务端每 15 秒巡检一次，30 秒没有任何消息（含客户端每 50ms 上报的输入）就把人摘出房间；
  公网经反向代理时 TCP 常常不会关、WS 层 pong 还可能被代理代答，所以判定用的是应用层消息而不是协议层心跳。
- 一台机器跑服务端即可：`node server.js`，同一 Wi-Fi 下手机打开终端打印的局域网地址。

部署到云服务器（systemd + Nginx 反代 WebSocket）见 [`docs/deploy.md`](docs/deploy.md)。

## 难度怎么涨

无尽模式里怪物数值是**两层缩放相乘**：

```
怪物血量 = 基础 × (1 + 0.10 × (层数-1)) × 威胁倍率
怪物攻击 = 基础 × (1 + 0.06 × (层数-1)) × (0.9 + 0.1 × 威胁倍率)
```

- **层数成长**：每深一层血量 +10%、攻击 +6%，线性、不封顶。
- **威胁倍率**：按玩家**面板 DPS**（攻击力 × 攻速 × 暴击期望，取手上两把武器里更高的那把）相对「第 1 层开局」的比值，开 0.4 次方后夹在 **0.85 ~ 3.2** 之间。

意思是：你越强，怪也跟着变硬，但只吃到你涨幅的一部分——所以仍然能感觉到自己在变强，只是不会一路碾压。全部参数集中在 `engine.js` 的 `SCALING`。

## 已实现

- **实时战斗**：像素级自由移动、分轴碰撞（可贴墙滑行）、鼠标定向攻击与冷却、投射物、近战扇形判定、命中无敌帧。
- **随机地图**：64×40，房间+走廊为主，每三层一层洞穴（2、5、8…）；每层 1 间商店，**50%** 概率额外有 1 个隐藏房（挥砍或射穿裂墙进入）。右上角有**小地图**，走过的地形会画上去，楼梯、商店、宝箱常亮，视野内的敌人标红点。
- **视野**：递归阴影投射，**探索过的地形永久照亮**；敌人与物品只在当前视野内可见。
- **打击反馈**：WebAudio 实时合成的音效（零音频素材）、伤害飘字、暴击震屏、受伤闪红、挥砍刀光。
- **敌人**：史莱姆 / 地鼠 / 邪术师（远程，保持距离射击）/ 暴徒 / 速灵（极快，有几率闪避）/ 石傀儡（厚重，一拳把人打飞）/ 掷弹手（抛炸弹，落点范围爆炸）/ 层主 / 深渊领主（每 5 层出现，半血召唤援军）。用 BFS 流场寻路，会绕墙绕拐角；只在身边约 12 格内被惊动，跟丢后会重新睡下。
- **层主**：守在楼梯旁，不主动出击，玩家靠近才应战，走远就回原位。
- **地图**：洞穴层会成片堆出碎石群当掩体（墙占比 ~37%，原来是 26% 的大空场），撒完把被围死的零碎空地封成岩体，保证走得通的地方都连通；敌人按 3 格间距铺开，不会在空场里堆成一团。
- **局内成长**：经验升级 → 暂停三选一（10 种强化池），三条流派（攻速 / 暴击 / 吸血）都能走通。
- **层主奖励**：击败后解锁楼梯并回复 25% 生命；每 5 层的层主是**深渊领主**（血量与赏格都更高）。
- **无尽向下**：没有终点层，只有死亡或主动收手才会结束。每通过 3 层会问一次「继续深入 / 就此收手」，收手则结算并回到标题。
- **局外成长**：晶石（只由 Boss 掉落）→ 生命上限、攻击力各 5 级。
- **道具**：金币、药水、宝箱（三选一，纯武器时可跳过并保留）、生命护符（死亡自动复活一次），走近自动拾取。**金币主要靠杀怪掉落**，地上捡的只是零头；用途是去**商店**买武器与增益。
- **存档**：`data/meta.json`，写盘前自动备份为 `meta.bak.json`。局内进度不落盘。
- **调试**：`?` 无；`/api/debug/shot` 可把画面存成 `data/shot.png`。

## 目录结构

```
server.js              零依赖 HTTP 服务：静态文件（含 /src/ 映射）+ 存档接口
public/
  index.html
  style.css
  client.js            渲染、输入、相机、HUD、覆盖层
  engine.js            实时引擎：世界、碰撞、战斗、AI（UMD，可在 Node 里测）
  audio.js             WebAudio 合成音效（零素材）
  assets/atlas.png     生成的图集
  assets/atlas.json    帧索引
src/
  mapgen.js            房间/洞穴/隐藏房生成（UMD，浏览器与 Node 共用）
  fov.js               视野（递归阴影投射，UMD）
  rng.js               可复现随机数（UMD）
  save.js              局外存档读写
tools/
  gen-assets.js        用 zlib 手写 PNG，生成 16×16 像素图集
  engine-test.js       实时引擎单元测试（不启动服务器）
  gen-test.js          地图生成压力测试
data/
  meta.json            局外存档（首次运行自动生成）
```

## 开发

```bash
node tools/gen-assets.js      # 重新生成像素图集（改完美术后跑）
node tools/engine-test.js     # 实时引擎测试
node tools/gen-test.js 200    # 每层生成 200 次，检查连通性
```

### 接口

服务器不再参与游戏逻辑，只提供：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/meta` | 读取局外存档 |
| POST | `/api/meta` | 保存局外存档（服务端会规范化校验） |
| POST | `/api/meta/reset` | 清空局外存档 |
| POST | `/api/debug/shot` | `{data:"data:image/png;base64,..."}` 存画面（调试） |
| GET | `/src/*.js` | 浏览器直接加载共享模块（UMD） |

## 已知限制

- **局内进度不落盘**：关闭页面会丢失当前这一局（局外晶石和升级会保留）。
- 数值（敌人强度、掉落、升级价格）是按「明快刷怪」拍的第一版，需要试玩调。
- 没有 BGM（只有音效）、没有存档槽、没有成就系统、没有移动端适配。
- 实时化的改造推翻了原设计里「回合制」的结论，见 `docs/design-qa.md` 的变更记录。
- 中文使用系统字体（像素中文字体体积大且有版权问题）。
